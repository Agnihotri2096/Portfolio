## ⚡ Architecture & Technology Stack

The platform is engineered using modern, high-performance web and graphics standards:

- **Framework**: React 18, TypeScript, Vite
- **3D Graphics & WebGL**: Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`), Rapier Physics (`@react-three/rapier`)
- **Animation & Physics**: GSAP 3, ScrollTrigger, ScrollSmoother, SplitText
- **Styling**: Modern CSS3 with technical-editorial styling, CSS custom properties, and responsive layout choreography
- **Icons**: React Icons (Fa6, Md, Tb)

## 🛠️ Development & Build

### Install Dependencies
```bash
npm install
```

### Run Local Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Lint Codebase
```bash
npm run lint
```
